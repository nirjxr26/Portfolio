## What I do.

### CI/CD Pipelines
**Ship faster, break less.**
Every change gets built, tested, and deployed automatically — no step depends on someone remembering it.

### Vulnerability Patching
**Fixed, not filed.**
Vulnerabilities get triaged by real severity and closed inside SLA — before they're exploited, not after.

### Secure by default.
**Nothing left open.**
Access is scoped tight and secrets stay encrypted from the first commit — security isn't a later step.

### Monitoring & Alerting
**Know before it breaks.**
Systems are instrumented so problems surface on a dashboard, not from a user complaint.

### Incident Response & Recovery
**Fail loud, recover fast.**
Rollback paths and runbooks exist before something breaks — not improvised while it's on fire.

## How I think.

### Systems Fluency
**Where pieces connect.**
I've built across the frontend, backend, infra, and pipeline layers — enough to see how a change in one breaks another.

### System Design
**Whiteboard before code.**
Failure points get mapped on paper first. Cheaper to redesign a diagram than rewrite production code.

### Cost Awareness
**Efficient, not cheap.**
I size systems to what they actually need to handle, not what looks impressive on a spec sheet.

### Code Quality
**Checked before it's seen.**
Style, types, and tests are enforced automatically — so review time goes to design decisions, not typos.

### Fault Isolation
**Small blast radius.**
Components are scoped so one failure doesn't cascade — and the cause is obvious immediately.
